Combine CSV columns offline

This page contains no patient data. It reads files you select locally and makes a new download. It does not upload anything, contact any server, modify originals, or send data to n8n or GoHighLevel. You can disconnect the internet while combining.

Important: Columns are placed side by side using each file's original row order. They are not matched by patient ID. A row may contain information about different patients. Shorter files are padded with blank cells. No source values are removed, reformatted, renumbered or deduplicated.
  1. Select the 10 extracted CSV files from the original 51191 folder.
  2. Leave encoding on UTF-8 unless you know the originals use another encoding. UTF-16 byte-order marks are detected.
  3. Click Combine. Save the downloaded file locally.
  4. Upload it yourself to the intended private Google Drive folder. Do not make the file public.

Only CSV files are supported. The reviewed folder contained 10 CSV files and no Excel workbooks. If you now have Excel files, do not rename them to .csv; keep them separate and report them.
